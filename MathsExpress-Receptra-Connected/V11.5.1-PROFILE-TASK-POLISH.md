# MathsExpress v11.5.1 — profile, character and task polish

Changes in this build:
- Character skin colour can be changed.
- Primary/secondary top colours and pants colour can be changed.
- Clothes styles: Classic, Sport, Varsity and Hoodie.
- Character is shifted upward so it never covers the student's name.
- Profile name is shown cleanly once inside the character card.
- Character controls are available from Locker / Profile.
- Pomodoro / Focus timer is permanently visible in the assignment top bar.
- Clicking the task Focus timer opens its timer controls.
- Focus timer continues updating while the student works.
- Assignment header, progress dots, titles and answers now wrap/scroll safely on smaller screens.
- Profile and assignment layout have extra overlap/clipping protection.
- Keeps v11.5.0 AI chat auto-clear behavior.
