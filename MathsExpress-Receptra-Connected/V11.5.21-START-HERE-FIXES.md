## Client fixes
- Signup: students enter the class code first (joined via the rate-limited `mathrift_join_class` right after the
  account is created; no anonymous code lookup, which would allow enumeration). Password is entered twice.
- Sign out is in the header (and the ☰ menu), not only in a Profile backup card.
- `robots.txt`, `sitemap.xml`, canonical/og URLs and `file:` fallbacks no longer point at the dead netlify domain.
- Startup fail-safe moved from an inline script (blocked by CSP, never ran) to `startup-failsafe.js`.
  External file instead of a CSP hash: the hash would break on any edit, and its `onclick` was also blocked.
- "Create task" removed from the ☰ dropdown (the floating teacher button and ⌘/Ctrl+Shift+A remain).
- Driving game remnants removed: owner-console drive-score buttons, 9 Maths Drive achievements, 10 vehicle skins in the shop.
- Friend challenge codes are real: `MX` + year + 4 random chars; the code seeds the questions, so everyone with the
  same code gets the same 10 questions and can compare scores. No server needed.
- Multiple choice: A/B/C/D (or 1–4) selects an option; ignored while typing in a field.
- Loading screen restyled to the app palette with a progress cue and dark-mode support; maintenance screen
  explains that work is safe, has "Check again" and re-checks every minute.
- Dark mode / dark theme / high contrast: hand-written high-contrast rules now cover every element in the app,
  and `tools/gen-dark-overrides.py` generates dark equivalents for hardcoded light surfaces, dark text and light
  borders. Re-run it after styling changes: `python3 -I tools/gen-dark-overrides.py public/styles.css`.
- Accessibility buttons (student settings, Font & Keyboard tool) now open Tools → Accessibility.
- Textbook chapter list: the unlabelled number beside each chapter is now "N lessons".
