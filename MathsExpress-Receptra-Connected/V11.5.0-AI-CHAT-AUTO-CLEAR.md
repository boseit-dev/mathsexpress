# MathsExpress v11.5.0 — AI chat auto-clear

- AI Helper chat now resets automatically whenever the student moves to a different question.
- Starting a new task, lesson, assignment, or custom worksheet starts a fresh AI chat.
- Leaving/completing the current assignment clears the stored AI chat.
- A context fingerprint prevents old AI messages from reappearing even if a navigation path misses an explicit reset.
- Manual Clear chat still works.
- Service-worker cache bumped to `mathsexpress-v11-5-0`.
