# MathsExpress v11.5.27: self-directed accounts, and the rest of the PDF list

**Status:** the source code is ready. The `20261014_01` plans migration was updated to add `in_class` (the 33-check live test still applies). **Nothing is deployed.**

## Your requests
| Request | Done |
|---|---|
| Accounts without a school are self-directed, with no class or school features | The class code is now **optional** at sign-up ("Leave blank to learn on your own"). Students who aren't in any class don't see Assignments, class tasks, parents and school links, class games or class challenges. The Assignments page sends them to Learn instead. Their profile has a "Have a school class code?" button for joining later. |

## Remaining PDF items now done
- **Learn tab, simpler:**
  - Placement test card, mistakes due for review, and "Your topics".
  - Everything else is folded under "Browse all skills, recommendations and more".
- **Progress bar for each topic (Mathspace style).** Each topic advances when you pass its **10-question check-in** on the next skill.
- **Skill map.**
  - Every skill in each strand is joined by arrows.
  - Colours: green = mastered, yellow = learning, red = needs work, grey = not started.
  - Each skill shows what it unlocks next. Clicking one starts it.
- **Confidence score.** Calculated from accuracy, difficulty, number of attempts and how recently the skill was practised, not just a percentage.
- **Wrong answers come back.**
  - They're saved with the full question, the student's answer and the worked solution.
  - They come back 2 days later as a "Mistake review".
  - "See explanations" shows why each one was wrong.
- **Placement test for new students.**
  - 12 questions across 4 strands, at the year below, their own year and the year above.
  - Only right-first-try answers count.
  - It sets the starting level in each strand and marks skills below that level as secure.
- **Clove coaches from progress.**
  - The AI gets a factual summary: strongest skills, skills needing work and recent mistakes. It's told never to invent progress.
  - It's renamed to Clove.
  - The summary is turned off in test mode.
- **Real adaptivity.** In adaptive practice, 2 right-first-try answers make the next question harder, and 2 retries make it easier.
- **Year 12 is now HSC level.**
  - Year 12 used the same easy generators as Year 11, for example log₁₀(1000) and sin 30°.
  - It now has chain and product rule, stationary points, area between curves, log and exponential equations, trig equations, limiting sums, the remainder theorem, composite and inverse functions, conditional probability, E(X), z-scores, annuities, the cosine rule, similar areas, shortest paths, break-even, depreciation and rate conversion.
  - Every answer is calculated from the same numbers shown in the question, and a test checks this.
- **AI marking of working-out** now first checks the working relates to *this* question. Unrelated working gets 0 marks.
- **Login security code (optional).** Turn it on from Profile → "Login security code": scan a QR code in an authenticator app, and a 6-digit code is then needed at every login. It can be turned off again.
- **Owner can create accounts** (Owner Console → Create account):
  - set email, name, role (including bug tester), year, plan and an optional class code;
  - the person is emailed a link to choose their own password, so the owner never sees it;
  - this needs the `SUPABASE_SERVICE_ROLE_KEY` Worker secret.
- **Printing:**
  - All printouts now have the MathsExpress logo, name, date and footer.
  - Fixed: 2 print buttons always said "pop-up blocked".
- **Textbook previews:** a ✏️ Draw layer with colour and Clear over the textbook preview.
- **Task textbook:** an ⤢ Expand button makes it nearly full-screen.
- **Clove throughout, animated:**
  - Each pose has its own animation: bob, wiggle, jump, tilt or breathe.
  - Clove now appears in the AI chat, the upgrade window, the Learn hub, mistake explanations, the security code screen and the completion screens.
  - Clove stays still when reduced motion is on.
- **Level / time / points / coins strip:** one clean segmented bar, with a ⏱ timer icon.
- **Teacher dashboard navigation:**
  - A new "Start here" bar with Set work, Live class, Results and Class game.
  - A "What do you want to do?" search box that finds any teacher tool.
- **Buttons that did nothing:** the school switcher and the Learn and Learning Path year pickers had no code behind them. They're fixed, and a new test fails the build if any button has no handler.
