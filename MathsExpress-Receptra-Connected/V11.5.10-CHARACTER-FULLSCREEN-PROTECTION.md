# MathsExpress v11.5.10

- Shop cards render cosmetic previews instead of only emoji icons.
- Outfit cards show a mini full-body character wearing the outfit.
- Outfit preview patterns visually match each named cosmetic.
- Skin/clothes controls update a live avatar preview without saving until Save character is pressed.
- Reset preview no longer overwrites the saved character.
- Starting lessons, independent practice and assigned tasks requests fullscreen immediately.
- Task workspace blocks common right-click image-search, copy and drag routes.
- `display-capture` is disabled for site code through Permissions Policy. Browser-level Lens/screenshot tools cannot be completely disabled by a website.
- Supabase account inventory now accepts the cosmetic item IDs used by the shop.
