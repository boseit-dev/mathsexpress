# MathsExpress v11.5.25: fixes from CHECKLIST.md and MathsExpress.pdf

**Date:** 12 October 2026. **Status:** the source code and a new migration are ready. **Nothing is deployed, and the production database is unchanged.**

## Fixed or built in this release
| Checklist item | What changed |
|---|---|
| Class games: choose how long a game runs and which assignment it covers; not only algebra | The teacher game picker has **Length** (3–30 minutes), **Topic** (Number, Algebra, Measurement & Geometry, Statistics & Probability, Mixed), **Year level** and **Based on an assignment**. Picking an assignment fills in its topic and year. The server builds questions for every topic in every year from K to 12, and stops issuing questions when the time is up. |
| Don't show students how other students did | The server now withholds other players' right and wrong counts from students. A student sees team totals and their own answers; teachers still see everyone. |
| "Make the first answer right" / answer-position bias | In class games, the correct option was always the smallest number. Wrong options now sit on both sides of the answer and all options are shuffled. |
| The question can still be faintly seen behind "Return to fullscreen" | The overlay is solid, and the task underneath is hidden while it shows. |
| Regenerate the question when a student leaves fullscreen | An unanswered question is swapped for one of the same type with different numbers. For lessons it is swapped for another unused question of the same type. |
| Tools are jumbled and can't be searched | A search box on the Tools page searches every tab at once. |
| Make the calculator better and bigger | The calculator is larger with bigger keys, and has 4 new keys: abs, x³, 1/x and ×10ⁿ. |
| Rename MathsExpress AI to Clove | The helper title, chat label, avatar (🦊) and welcome message all say Clove. |
| Student assignments don't appear on admin accounts | Admin, owner and teacher home pages now list the latest tasks in their classes, plus any tasks assigned to them. |
| Completion screen: make it look better and give rewards for finishing | The new screen shows stars, an accuracy ring and stats. Self-paced practice pays **+15 coins and +30 XP**, checked on the server: at least 5 recorded answers since the last claim, at most 5 claims a day, and each run pays once. Assignments still use the existing completion reward. |
| 6–8 week seasons with XP, ranks, class competitions and cosmetic rewards | Seasons now run on the server and last **7 weeks**. Season XP comes from the reward ledger, so it resets each season while achievements, coins and items stay. Ranks run from Bronze to Champion. Finishing a season at Bronze or above unlocks a "Season ‹rank›" title that can't be bought. |
| Classes compete on accuracy and completed work | Class standings are 60% accuracy plus 40% of set work completed, for classes in the same school. The formula is shown on screen. |
| Shop: previews, show the item instead of an emoji, remove the car, more items | Avatars and themes now get real previews. The Locker shows each item's picture instead of an emoji. The 10 car skins are off sale (anyone who owns one keeps it). 8 new titles were added. |
| **Bug found:** every shop purchase failed on the server | `account_inventory` only accepted 4 consumable item names, so buying any outfit, pet, title and so on raised an error. The rule now also accepts cosmetic item names (the format is still checked). |
| Teachers see who is doing well, struggling or inactive, click a group then a student to see wrong answers; time on task; whether students are in another tab | **Live class** in the class report shows three counts that refresh every 10 seconds. Clicking a group lists its students with the reason. Clicking a student shows their focus state, times they left the tab, accuracy and answering time over the last 30 minutes, current assignment, and wrong answers from the last 14 days. The grouping rules are shown on screen. |
| Separate login portals for K–6 and 7–12 | `app.html?auth=login&portal=primary` or `portal=secondary` gives each portal its own look and wording, with a switch between them. The choice is remembered on the device, and the home page links to both. |
| Home page: show plans, look professional | A **Plans** section was added (Student, Teacher, School). No prices are shown because none were given. Tell me the prices and I'll add them. |
| Home page: a slide showing you visited schools to ask for features | A "We visited schools and asked what they needed" slideshow pairs 5 requests with the feature built for each. It pauses when the visitor has reduced motion turned on. |
