# MathsExpress v11.5.24 — every missing RPC built, all three pending migrations tested on the live schema

**Date:** 12 October 2026  **Status:** source + migrations ready. **Not deployed. No production data or schema changed.**
Production and GitHub `main` were both confirmed still at v11.5.20 (service-worker cache `mathsexpress-v11-5-20-receptra`, GitHub head `6d71c09`), so nothing newer was overwritten.

## What changed

### 1. Full RPC re-audit (client + Worker vs live database)
212 distinct RPCs are called by `deploy-app.js`, `deploy-core-1/2.js`, `v7-features.js`, `quick-assign-due.js` and `worker.js`.
**25 did not exist** in the live project (the handoff listed 19; the Worker's parent-email and Canvas helpers were also missing).
`v7_rollover_class` was reported missing in an earlier pass but exists live and was left untouched.

### 2. `supabase/migrations/20261012_01_missing_rpcs.sql` (NEW) — builds all 24 database ones
| Area | RPCs | Notes |
|---|---|---|
| Owner console | `owner_adjust_user_rewards`, `owner_update_user_profile` | Owner/Admin only; clamped to DB limits; every change written to `mathsexpress_audit_log` |
| Daily missions | `claim_daily_mission` | Completion is checked against **server evidence** for the Sydney day (daily attempts, assignment answers, reward XP). Pays once per mission per day via the reward-event ledger |
| Reviewed Question Studio | `save_authored_question`, `list_authored_questions`, `authored_question_stats`, `review_authored_question` | Extends `mathsexpress_custom_questions` (new nullable columns + `review_status`). Only Owner/Admin/Content editor can publish |
| Task reports | `task_question_report`, `task_question_detail`, `reassign_assignment` | Built from real `mathrift_question_attempts` (latest answer per student per question). Reassign = fresh copy with new due date and the same targets |
| School reports | `school_usage_dashboard`, `engagement_class_comparison`, `standards_growth`, `school_standards_proficiency` | Real activity/attempt/IRT rows only. Comparison formula is stated in the response (participation %, 20 questions/week practice target) |
| Parent email | `queue_parent_email`, `my_parent_email_outbox`, `parent_email_outbox_payload`, `mark_parent_email_outbox`, `parent_progress_email_payload`, `teacher_parent_message_email_payload` | New `mathsexpress_parent_email_outbox` table. Refuses to queue when no guardian email is linked; a sent email cannot be re-sent |
| Canvas | `save_canvas_assignment_map`, `save_canvas_user_map`, `canvas_grade_queue`, `mark_canvas_grade_queue` | New `mathsexpress_canvas_grade_queue`. Completed attempts are queued once; a newer attempt re-queues. Grades are only sent by the Worker when Canvas credentials are configured |

All new tables: RLS on, no direct grants. All new functions: `SECURITY DEFINER`, fixed `search_path`, `auth.uid()` checks, EXECUTE revoked from `public`/`anon`, granted to `authenticated`.

- `tools/test-migration-20261012.sql` — the live, rolled-back test (below).
- `tests/v11-5-24-rpc-coverage.test.cjs` + `tests/fixtures/live-public-functions-2026-10-12.txt` — fails the build if the client or Worker calls an RPC that is neither live nor created by a migration. Confirmed to fail when the new migration is removed.
