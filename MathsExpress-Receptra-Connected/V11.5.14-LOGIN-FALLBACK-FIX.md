# MathsExpress v11.5.14 — Login connection fix

- Fixed the login screen showing “Could not reach the account service” when the optional custom Supabase login Edge Function is unavailable.
- Email/password login now safely falls back to Supabase Auth directly if the custom login function cannot be reached.
- Added the same fallback when the custom login function returns HTTP 404.
- Username login continues to use the custom server login route because Supabase password auth requires an email address.
- Bumped the app auth bundle and service-worker cache version so browsers receive the fix after deployment.
