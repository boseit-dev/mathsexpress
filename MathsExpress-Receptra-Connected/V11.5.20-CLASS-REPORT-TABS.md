# MathsExpress v11.5.20 — Class Report Tabs

Fixes "these buttons don't work" on the class report.

## Root cause

The tab bar was never wired up. It rendered as plain text:

```html
<div class="class-report-tabs"><span class="active">Insights</span><span>Activity</span>
<span>Mastery</span><span>Tasks</span><span>Gradebook</span></div>
```

Five `<span>` elements — no button, no `data-action`, no handler anywhere in the
codebase. They were decoration that looked interactive, so clicking them could
never have done anything.

Meanwhile all four report panels rendered stacked on top of each other, which
is part of why this page reads as cluttered.

## What changed

The tabs are now real buttons that show one panel at a time, with `role="tab"`,
`aria-selected` and a visible focus ring. Switching is done in place by toggling
`hidden`, so no data is refetched and scroll position is preserved.

The five labels did not match the four panels that exist:

| Tab | Panel |
|---|---|
| Insights | Class Insights |
| Planner | Planner — had a panel but no tab |
| Mastery | Class Mastery Report |
| Tasks | Class Tasks Report |

**Activity** and **Gradebook** are removed. Neither had a panel, and neither has
anything to point at: `scorecardModal` is per-assignment and already reachable
from the Tasks panel, and `listActivity` returns the signed-in user's own rows
rather than the class's. A tab that opens nothing is the problem being fixed,
not a feature. Real Activity and Gradebook views would need deciding on and
building; they are not a rename away.

## Verified

The switching was exercised in a browser through the application's own
delegated click handler: exactly one panel visible at a time, `active` and
`aria-selected` following the selection, and returning to a previous tab works.
31/31 tests pass.

## Separate finding

While auditing the "More tools" row for the same class of bug, every one of its
eleven buttons turned out to have a handler. Probing instead revealed something
larger: 30 of the 205 database functions the client calls do not exist in the
live project. That is recorded separately and is not addressed here.
