## Auto-complete bot (only the owner can give access)
- The owner always has access. In the Owner Console, open a user and use **Auto-complete bot → Give access / Remove access**. Admins can't grant access, and nobody can grant it to themselves. This is enforced on the server.
- On a task, a 🤖 **Auto-complete** button answers each question through the normal submit path. It handles typed answers, multiple choice and coordinate/graph-point questions. It pauses on question types it can't fill (matching, drag-and-drop, multi-part) and on questions that need working out.
- On teacher assignments, each use is logged as **"bot autocomplete"** in the assignment's integrity timeline. The server only accepts that log entry from people who actually have bot access.
