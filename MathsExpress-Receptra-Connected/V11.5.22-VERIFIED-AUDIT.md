# MathsExpress v11.5.22 — ZIP-level audit and fixes

**Date:** 11 October 2026

**Status:** Source-only update. Not deployed. Existing production database not modified. No claim of full production validation.

## Verified changes

1. **Offline privacy:** The service worker no longer intercepts/caches Supabase API requests, signed-in HTTP requests, or arbitrary page routes. Only known public static assets qualify for offline caching. Cache version bumped to remove the previous cache on activation.
2. **Class games:** Removed calls to unimplemented `mathsexpress_class_game_state_v114` and `mathsexpress_class_game_snapshot_v114` RPCs. Instead, use the real `mathsexpress_class_game_leaderboard` RPC to display scores.
3. **Class-game team labels:** The real server uses **Blue / Gold**. The live scoreboard and team leaderboards now display Blue / Gold rather than incorrectly relabeling Gold as Red. Added Gold colours, including dark mode.
4. **Missing game engine:** Until a real server game-state engine exists, display *real scores* rather than invented football positions, mastery bars, and win conditions.
5. **Answer double-click guard:** Added a per-question in-page deduplication guard, including when a response might have succeeded but timed out. **Important:** This is not a substitute for server-side idempotency across tabs, devices, or refreshes.
6. **Power tools:** Maths Duels now opens the working shared-code Friend Challenge. The live leaderboard loads real server data. The fabricated game replay, fabricated integrity metrics, and nonfunctional menu entries were removed or replaced with truthful unavailable states.
7. **Learning data:** The "Run Diagnostic" tool now launches the real interactive Discovery Check-In, instead of inventing results from existing mastery. Confidence and error-analysis tools no longer substitute sample data for real student results.
8. **School tools:** Removed imaginary timetable and resource-library entries. Attendance does not silently fall back to made-up students or mark everyone present.
9. **Exam countdown:** Reads the next dated exam/test/assessment from saved calendar entries instead of showing a made-up 21-day countdown.
10. **Routing:** Removed dead `.netlify/functions/*` fallback URLs from client API request lists, retaining the Cloudflare `/api/*` endpoints.
11. **Release:** Bumped changed assets to `v11.5.22`, service-worker cache to `mathsexpress-v11-5-22-receptra`, and corrected the app footer version.

## NOT proven / remaining blockers

**Do not tell users everything is perfect or production-ready.** Full validation needs live authenticated tests in student, teacher, parent and owner roles, across screen sizes, light/dark/high-contrast modes. Browser navigation in this test environment returned `ERR_BLOCKED_BY_ADMINISTRATOR`; visual screenshots could not be captured. Real Supabase and Cloudflare integrations were not exercised.

- Production remains at the version documented in the original handoff unless you deploy. First verify no one else has deployed, then apply `supabase/migrations/20261011_01_discussion_and_parent_links.sql` before deploying this release. **Do not apply migrations blindly to a database that has changed since this ZIP.**
- **Database game engine and idempotency:** Class-game per-mode server state still missing, and `mathsexpress_class_game_answer` does not accept a question key. Browser-side guards cannot stop duplicates from multiple devices or independent tabs.
- **RPC mismatches / absent backends:** Reviewed Question Studio, reward adjustments, Canvas queue/maps, parent email queue, school usage/growth report signatures, standards reports, daily-mission claiming, reassigning assignments, other reports and more remain blocked by missing or incompatible RPCs. See `MathsExpress-REMAINING-WORK.md` for the detailed list. Verify against the current live DB before writing a migration; the schema has been edited in the dashboard.
- **Daily attempts:** `recordDailyQuestionAttempt` still intentionally does nothing. Adding an attempt-tracking table/RPC is separate from XP reward tracking and has not been done.
- **Email verification:** Supabase Auth and the signup Edge Function still require coordinated changes. Do not assume signup requires verification just because it displays a message.
- **Historical result quality:** Discovery Check-In / Fix Mode records before v11.5.19 may be wrong. Correcting historical records requires a product/data-retention decision and backups; this release does not rewrite them.
- **Content and curriculum:** NSW codes, Year 12 topic depth, and licensed textbook mapping were not independently validated.
- **Worker build connection:** The source archive contains a local git repository but this release is not connected to automatic Cloudflare Workers Builds.
