SHAPED IN CLASSROOMS

We visited schools and asked what they needed.

We took MathsExpress into schools and asked teachers and students what would actually help. Their requests became features.

“We need to pick the topic and how long a class game runs.”

Class games now let teachers choose the topic, year level, length and the assignment they practise.

“Students shouldn’t see everyone else’s wrong answers.”

In class games each student only sees their own results. Teachers still see the whole class.

“The tools are hard to find.”

Every tool is now searchable from one box.

“Finishing work should feel rewarding.”

Completing practice earns coins and XP, and seasons rank classes on accuracy and work completed, not on speed.

“Students copy questions into AI tools.”

When a student leaves fullscreen during a task, the question is hidden and replaced with a new version.
